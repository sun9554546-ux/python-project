# Preview
Run the app using the README steps, then open `http://127.0.0.1:5000`.

The home page contains the LibTrack header, search bar, stylized book covers, availability counts, and a floating book icon at the bottom-right. Clicking the icon opens an admin password modal. Enter `1234` for the local demo. After successful login, the admin dashboard shows summary cards, inventory management, issue/return controls, recent loans, and CSV export.
